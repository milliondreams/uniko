# Phase 5: FS/Shell/Git Integration + Cross-Agent Sharing + Organization/Team Support

## Objective

Phase 5 builds Layer 4 integration surfaces that extend uniko beyond a core
memory system into practical developer tooling. File systems become
knowledge-aware, git history becomes episodic memory, shell commands become
semantic searches, organizations get access-controlled shared knowledge, and
Python developers get native bindings via PyO3.

## Sub-Phases

| File | Description |
|------|-------------|
| `sub-01-integration-surfaces.md` | Shadow filesystem, git integration, semantic shell, organization/team multi-tenant support, and Python binding via PyO3 |

## Key Milestone

> Layer 4 integration surfaces

## Prerequisites

Phase 4 complete -- MCP server operational, benchmark numbers published, system performance validated against all 5 benchmark suites.

## Definition of Done

- Shadow filesystem provides knowledge-aware file operations that integrate with the memory graph.
- Git integration captures repository history as episodic memory with commit, branch, and diff awareness.
- Semantic shell translates natural language into contextual shell operations using memory.
- Organization/team support provides multi-tenant access-controlled shared knowledge spaces.
- Cross-agent sharing enables multiple agents to read from and contribute to shared memory.
- Python binding via PyO3 gives Python developers native access to the full uniko API.
- All sub-phase test suites pass.
